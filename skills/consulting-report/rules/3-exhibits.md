# 3. 도표, 표, 캡처

보고서의 그림은 컨설팅 보고서처럼 절제해서 만듭니다. 흰 바탕에 주황과 회색, 각진 막대, 막대마다 값을 적습니다.
대시보드를 흉내 낸 그림(베이지 바탕, 둥근 카드, 알약 모양 칩, 색 점, 그림자, 아이콘)은 만들지 않습니다. AI가 만든 화면처럼 보여 보고서의 신뢰를 떨어뜨립니다.

## 3.1 원칙

1. **숫자를 지어내지 않습니다.** 도표의 모든 값은 원자료(데이터베이스 조회, 측정 결과 파일)에서 옵니다. 설정 파일 맨 위에 출처와 세는 기준을 적습니다. 합계는 빌드 스크립트에서 다시 더해 확인합니다.
2. **그림 하나에 메시지 하나.** 흐름도와 계산 예시를 한 그림에 묶지 않습니다.
3. **일부만 고르지 않습니다.** 비교 대상은 전부 보여 줍니다. 골라서 보여 주면 독자가 의심합니다.
4. **색의 뜻을 고정합니다.** 보고서 전체에서 같은 대상은 같은 색입니다. 가장 중요한 값에만 강조색을 씁니다.
5. **그림 속 글자는 최소로.** 축 눈금, 단위, 범례, 값만 둡니다. 제목과 출처는 그림 밖 Word 글로 씁니다. 사람이 Word에서 고칠 수 있어야 하기 때문입니다.
6. **그림 속 용어와 본문 용어를 같게 씁니다.** 한쪽을 바꾸면 다른 쪽도 바꿉니다.
7. **캡처 내용을 고치지 않습니다.** 자르기와 테두리만 합니다. 색 반전, 글자 덧씌우기, 합성을 하지 않습니다.

## 3.2 문법

| 항목 | 규칙 |
| --- | --- |
| 바탕 | 흰색. 테두리, 둥근 모서리, 그림자를 쓰지 않습니다 |
| 색 | 주황 `#dc5218`, `#eaa974`, `#f2cca8`과 회색 `#ccd0d5`, `#a2a7b1`. 다른 색을 섞지 않습니다 |
| 막대 | 모서리가 각진 막대. 묶음 안 막대는 붙여 그리고, 막대마다 값을 적습니다 |
| 쌓은 막대 | 구간 사이는 흰 선 1px, 값은 합계만 적습니다. 3계열은 `#dc5218`, `#eaa974`, `#7b808a` 순서입니다 |
| 축 | 눈금선 없이 바닥 실선만 둡니다. 꺾은선만 옅은 가로 눈금선을 둡니다 |
| 범례 | 도표 아래 가운데. 계열이 하나면 넣지 않습니다 |
| 제목 | 도표 위 왼쪽에 `도표 N. 제목 (단위: 건)`. 번호는 보통, 제목은 굵게, 단위는 회색입니다. 표는 `표 N.` |
| 출처 | 도표 바로 아래 `출처:` 한 줄(10pt 회색) |
| 표 | 회색 머리줄 띠 `#dfe2e5`, 가로 실선만, 세로줄 없음, 숫자 열은 오른쪽 정렬 |
| 캡처 | 빈 곳을 자르고 보여 줄 자리에 주황 실선 테두리만 얹습니다 |

## 3.3 도표 종류 고르기

| 보여 줄 것 | 종류 | `type` |
| --- | --- | --- |
| 항목별 기간 비교 | 묶은 막대 | `column` |
| 기간별 양과 그 구성 | 쌓은 막대 | `column` + `"stacked": true` |
| 같은 축으로 여러 묶음 비교 | 소제목 띠를 단 작은 막대 여러 개 | `column` + `panels` |
| 항목 이름이 길거나 많음 | 가로 막대 | `bar` |
| 여러 계열의 추이 | 꺾은선 | `line` |
| 전체 안의 비중 | 도넛 | `donut` |

도넛은 조각이 여섯 개를 넘으면 가로 막대로 바꿉니다.

## 3.4 도표 만들기

설정 파일(JSON) 하나에 도표를 적고 실행합니다.

```bash
node tools/render.mjs <설정.json> --out <결과 폴더>
```

결과는 `<도표 id>.png`입니다. 폭 680px 기준으로 그려 3배 해상도로 저장합니다. 본문 폭 165mm에 넣으면 글자가 9pt 안팎으로 읽힙니다.

| 종류 | 꼭 적는 것 | 고를 수 있는 것 |
| --- | --- | --- |
| 묶은 막대 | `categories`, `series` | `height`, `yTicks`, `yMax`, `valueLabels`, `barWidth` |
| 쌓은 막대 | `categories`, `series` | `height`, `yTicks`, `totalLabels`, `barWidth` |
| 소제목 띠 | `categories`, `panels[].title`, `panels[].series` | `height`, `yTicks` |
| 가로 막대 | `categories`, `series` | `xTicks`, `xMax`, `labelWidth`, `rowHeight`, `valueLabels` |
| 꺾은선 | `categories`, `series` | `height`, `yTicks`, `valueLabels` |
| 도넛 | `slices` (`name`, `value`) | `subtitle`, `size` |

모든 종류에 쓸 수 있는 칸입니다.

| 칸 | 뜻 |
| --- | --- |
| `id` | 결과 파일 이름. 겹치면 멈춥니다 |
| `series` | `{"name": "2026년", "values": [64, 12, 7]}` 모양. 빈 값은 `null` |
| `color` | 계열 하나의 색만 바꿉니다 |
| `pointColors` | 묶은 막대와 가로 막대에서 막대마다 색을 바꿉니다. 예: `["#dc5218", null, "#a2a7b1"]`. 비교 기준 막대만 회색으로 둘 때 씁니다 |
| `valueSuffix` | 값 뒤에 붙일 글자. 예: `"%"` |
| `legend` | `false`면 범례를 숨깁니다 |
| `subtitle` | 도표 바로 위 작은 설명 한 줄 |

가로축 이름을 두 줄로 쓰려면 `\n`을 넣습니다.

설정 파일 맨 위에는 아래 칸을 둘 수 있습니다.

| 칸 | 뜻 | 기본값 |
| --- | --- | --- |
| `width` | 그림 폭(CSS px) | `680` |
| `locale` | 숫자 표기 | `"ko-KR"` |
| `colors` | `{"series": [...], "stack": [...], "donut": [...]}`. 색 순서를 바꿉니다 | 3.2의 색 |

모든 종류의 예시는 [`examples/exhibits.json`](../examples/exhibits.json)에 있고, 그린 결과는 [`examples/out/`](../examples/out/)에 있습니다. 새 도표는 비슷한 것을 복사해 숫자만 바꿉니다.

## 3.5 캡처 가공

```bash
python3 tools/captures.py <설정.json> --src <원본 폴더> --out <결과 폴더>
```

설정 파일의 `captures`에 한 장씩 적습니다. 좌표는 원본 사진의 픽셀입니다.

```json
{ "id": "캡처_상품_후기", "file": "원본.png", "crop": [0, 120, 1280, 640], "marks": [[60, 470, 560, 230]] }
```

| 항목 | 기준 |
| --- | --- |
| 자르기 | 빈 여백을 자릅니다. 글이 중간에 잘리지 않는 줄에서 끊습니다. 화면을 가리는 입력창과 팝업은 뺍니다 |
| 테두리 | 보여 줄 자리마다 하나씩. 결과를 열어 위치가 맞는지 반드시 눈으로 확인합니다 |
| 바깥선 | 흰 화면이 흰 종이에 묻히지 않게 회색 1px 선을 자동으로 두릅니다 |
| 출처 줄 | `출처: <화면 이름> (<캡처 날짜> 캡처). 주황 테두리는 <보여 주려는 것>입니다.` |
| 캡처 날짜 | 파일 이름에 날짜가 있으면 그 날짜를 씁니다. 업로드 시각과 달라도 파일 이름이 맞습니다 |

도표와 캡처를 한 설정 파일에 함께 적어도 됩니다(`charts`와 `captures`).

## 3.6 표

표는 Word 안에서 만듭니다(`report_docx.data_table`, [4. Word 문서](4-document.md)). 그림으로 넣지 않습니다.

1. 회색 머리줄 띠, 가로 실선만 둡니다. 세로줄을 쓰지 않습니다.
2. 숫자 열은 오른쪽 정렬, 글 열은 왼쪽 정렬입니다.
3. 합계 줄은 굵게 씁니다.
4. 표 아래 주석은 `* `로 시작합니다.
5. 날마다 바뀌는 값(검색 순위 등)은 주석에 기준일을 적습니다. 예: `* 순위는 캡처한 날의 화면 기준이며 날마다 달라질 수 있습니다.`

## 3.7 함정

| 함정 | 대응 |
| --- | --- |
| 연주황과 연회색이 이웃하면 구분이 약합니다 | 쌓은 막대 3계열은 `#dc5218`, `#eaa974`, `#7b808a`를 씁니다. 묶은 막대는 값이 적혀 있어 괜찮습니다 |
| 캡처 테두리가 어긋납니다 | 좌표는 눈대중입니다. 결과 PNG를 한 장씩 열어 확인합니다 |
| 글꼴이 다르게 나옵니다 | `render.mjs`가 경고를 냅니다. `fonts/` 폴더가 스킬 폴더 안에 있는지 확인합니다 |
| 도표 글자가 작습니다 | 도표는 폭 680px 기준입니다. 문서에 165mm보다 좁게 넣으면 글자가 8pt 아래로 내려갑니다 |
| 네 자리 값이 옆 막대 값과 겹칩니다 | 막대가 값 글자보다 좁으면 겹칩니다. `barWidth`를 늘립니다(예시 도표 1은 38) |
| 도표 수가 많아 본문이 길어집니다 | 절마다 대표 그림 하나만 본문에 두고 나머지는 부록으로 보냅니다 |
